I am a software developer driven by a fascination for automation, efficient workflows, and secure digital architectures. With a unique background blending tech, UX/UI perspective, and pedagogical insights, I focus on building practical modules, cross-platform applications, and privacy-first utilities designed to simplify daily operations while keeping integrity intact.

I like to view technology through a holistic lens—analyzing not just how code runs, but how users interact with it, where the defensive vectors lie, and how repetitive processes can be seamlessly automated.

---

## ⚡ Core Philosophy & Workflow

- **Practical Automation:** Building modules, shell scripts, and background services that eliminate friction in daily tasks and optimize workflows.
- **Secure Systems & Cryptology:** Deep diving into secure communication frameworks, hybrid backend setups (Supabase/Firebase), cryptographic implementation, and defensive network security.
- **Human-Centric Engineering:** Leveraging an innate understanding of user psychology, human-computer interaction, and intuitive design patterns to build tools that are inherently resilient against social engineering risks.
- **Cross-Platform Delivery:** Deploying robust, high-fidelity mobile and web components crafted via Flutter and Android Studio.
